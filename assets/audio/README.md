Put your song file here and name it exactly:

    song.mp3

That's it — index.html already points to `assets/audio/song.mp3`, so once
the file exists here with that name, the mute/unmute button on the site
will play it automatically.

Notes:
- Any royalty-free or your own recorded piano/instrumental track works.
- Keep the file reasonably small (under ~5–8MB) so it loads quickly on GitHub Pages.
- If you want a different filename, update the `<source src="...">` line
  inside `index.html` (search for `assets/audio`).
